1. Program Overview

The McKnight Notification Service ("Service", "Program") is a private, personal SMS notification system operated by Mike McKnight as a sole proprietor. The Service sends transactional system alerts via Twilio to a single, pre-configured mobile phone number that belongs to the Operator.

The Service is not a consumer-facing product. There is no public sign-up form, no marketing, no third-party recipients, and no resale of messaging capacity.

2. Recipient

Messages are delivered to one recipient only: the Operator, on a mobile phone number that the Operator personally owns and controls. No other phone numbers are stored or messaged by the Service.

3. How Consent Is Obtained (Call to Action)

Because the Service has exactly one recipient — the Operator — consent is obtained by the Operator's own action at the time the Service is deployed:

  • The Operator manually enters his own mobile phone number into the Service's private configuration (a server-side environment variable) on his own infrastructure.
  • By performing that configuration step, the Operator affirmatively opts in to receive transactional SMS notifications from the Service on the configured number.
  • No other person can opt in, and no other person's phone number can be added — the configuration is private to the Operator's own server and is not exposed to any web form, API, or public interface.

This page documents that consent flow and serves as the publicly accessible Call-to-Action reference for the campaign.

4. Message Details

  • Message types: Transactional system notifications only — no marketing, promotional, or advertising content is ever sent.
  • Message frequency: Varies based on internal application activity. There is no fixed schedule.
  • Charges: Message and data rates may apply, depending on the Operator's mobile carrier plan.
  • Supported carriers: Major US carriers. Delivery on all carriers is not guaranteed.

5. Opt-Out and Help

The Operator may opt out at any time:

  • Reply STOP to any message to unsubscribe. One final confirmation message will be sent and no further messages will follow.
  • Reply HELP to any message for assistance, or contact the Operator at mike@mcknight4.com.
